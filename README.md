## About

I'm a **Venture Operator for Pan-African Tech** — I diagnose, architect, and execute. My background spans electrical engineering, product design, and full-stack software development. I help African founders go from idea → launch with systems that actually work in the local context.

- 🔭 Currently building: **T&C SaaS**, **Pan-African Tech Venture Studio**, and **GEO-optimized content systems**
- 🌱 Learning: private fine-tuning, agent orchestration at scale, hardware and embedded systems.
- 💬 Ask me about: venture architecture, brand identity systems, or building your MVP for the african market.
